# RexArticles

Кроссплатформенное GUI-приложение для автоматического поиска и сбора файлов принтов по артикулам из поставок WB и Ozon.

## Возможности

- разбор PDF-поставок WB и Ozon;
- поиск принтов в локальных, сетевых и облачных папках;
- SQLite-индексы с инкрементальным обновлением;
- поддержка REST API Яндекс Диска;
- светлая и тёмная системные темы;
- ручные уточнения артикулов и журналирование операций.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Пользовательские настройки, OAuth-токены, индексы и логи не хранятся в репозитории.
